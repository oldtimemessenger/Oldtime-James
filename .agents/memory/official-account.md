name: Official Oldtime account
description: The reserved official Oldtime identity and its permanent blue badge must survive backend changes.
---

The official Oldtime account owns the `oldtime` username, which no other account may claim. Its blue badge is permanent and must not depend on a paid subscription or the currently selected backend. The user selected this existing account as the editorial profiles' follow target and requested Social Engine admin access for it.

**Why:** the user explicitly asked for both rules to remain in effect if the app changes backends, then confirmed that the existing `@oldtime` account is the official follow target and should receive admin access.

**How to apply:** tie the rules and admin access to the stable account identity, preserve that identity during backend migrations, and carry equivalent reservation checks and permanent badge behavior into each backend adapter.
