Keep Saved and Archive private, as separate pages under Settings, never as profile tabs. Saved includes All, Collections, Reels, Posts and Audio. Collections are now explicitly requested, superseding the earlier instruction to remove their interface. Preserve existing saved data.

**Why:** The user explicitly requested this Settings arrangement and the Collections filter in the newer interface brief.

**How to apply:** Keep ordinary Save actions working; collection organization must not delete saves. Archive contains the owner's archived stories and posts, future archiving controls and explicit memory resharing; disabling future archiving must not erase existing memories.
