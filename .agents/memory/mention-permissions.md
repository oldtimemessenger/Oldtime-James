---
name: Mention permissions
description: Meaning of the “People you follow” tag-audience option.
---

For “Who can tag you?” → “People you follow,” allow a tag when the tagged account follows the person doing the tagging. Use the same relationship direction for search suggestions and publishing checks.

**Why:** The preference describes the tagged account’s audience choice; using the tagger’s follow list reverses that intent and can make suggestions disagree with publish-time checks.

**How to apply:** When adding mention surfaces or changing relationship storage, check tag eligibility from the tagged account’s point of view and reuse the same permission rule for read and write paths.
