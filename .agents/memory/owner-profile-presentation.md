---
name: Owner profile presentation
description: Owner profile actions and where profile view totals may appear.
---
Profile headers must not display view totals; view counts belong on individual content. The owner profile’s primary action is Edit profile, not a dashboard card. Keep supported social counts such as following and followers in the header. Visitor profiles retain Follow and Message actions. Covers must have a crisp full-bleed landscape crop, with a blurred/faded image continuing behind profile details and beneath Edit profile; remove white edges and keep top controls in place. Keep profile descriptors plain text rather than boxed chips, and give existing social counts clear visual emphasis. This rule applies to the profile header and does not remove analytics destinations elsewhere in the app.

**Why:** the user specified that views appear on content, not in the header, asked for an owner profile centered on editing rather than a dashboard, and most recently asked for a rectangular, edge-to-edge cover that fades under Edit profile. A confirmed profile save can still look stale if the cached cloud profile overrides the updated account.

**How to apply:** keep view totals attached to their individual posts, use the existing Edit profile flow as the owner’s main profile action, preserve visitor actions, keep the sharp cover crop landscape and let a soft darkened version fill/fade behind profile details through the edit button, and after a confirmed profile save synchronize the account session, persisted user, and matching cloud-profile cache before rerendering.
