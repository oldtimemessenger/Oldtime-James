---
name: Signup and Community personalization
description: Required signup interests, transparent optional official follow, and strong but controllable Community recommendations.
---

New accounts must choose at least three different interests. Signup visibly offers “Follow @oldtime for app updates”, unchecked by default; only an explicit opt-in follows it. Never follow secretly or retroactively change existing users’ relationships.

**Why:** the user requested minimum-three interests and later clarified that new accounts must start fresh with only recommendations/suggestions, not existing relationships or another member's Status.

**How to apply:** enforce supported, distinct interests on the server as well as in the signup interface. Only an explicit affirmative checkbox value follows the existing reserved official identity; never create a substitute account. Recommendation interests are private preferences unless the person separately chooses to put them on their public profile.

Community Discover should start with strong interest-aware recommendations and genuine suggested accounts. Following must remain chronological and follow-only. Respect filtering, mutes, blocks and privacy before recommending.

Home's Status strip must contain only the account's own Status and explicitly followed authors, including next/previous Status navigation. Fresh accounts have no inherited relationships, messages, saves, posts or Status history. Accounts without follows start on For You with clearly separate public recommendations.

**Why:** the user repeatedly objected to an unfamiliar member's Status appearing on a newly created account's Home page and said new accounts must start fresh.

**How to apply:** public visibility or a Discovery cache entry does not establish a relationship. Do not use public Status as a Home empty-state filler. Keep existing real records intact; fix membership and account scoping instead of deleting other users' content.

**Why:** the user wants Community to feel populated and useful, but previously required a clear distinction between followed posts and recommendations.

**How to apply:** provide real suggested accounts and transparent recommendation reasons in recommendation feeds; vary creators without manufacturing posts, people, engagement or trends. If eligible content is genuinely unavailable, explain it and provide useful discovery actions rather than inventing activity or overriding the person’s filters.
