---
name: Profile list privacy
description: User-confirmed defaults for followers and following visibility.
---

Other people must see followers hidden by default and following visible by default. Owners can always view both of their own lists and can change each visibility setting.

**Why:** The user explicitly selected “Followers hidden, following visible” when asked what other people should see by default.

**How to apply:** Enforce list access and preview-photo visibility on the server, not only in the interface. Preserve private-account and blocking rules, keep the existing prominent counts, and do not replace genuine member images with generated avatars.
