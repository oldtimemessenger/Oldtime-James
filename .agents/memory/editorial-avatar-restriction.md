---
name: Uploaded profile image restriction
description: Uploaded avatar images must not be used by any Oldtime account.
---

No account may use the uploaded avatar images. Do not auto-assign them or offer them as profile-photo choices. Use a member's own uploaded photo or the app's separate built-in avatar choices.

**Why:** The user explicitly said nobody may use the uploaded avatars.

**How to apply:** Keep the images out of account-photo choices and reject profile updates that reference them. When an account has no photo, use the standard built-in avatar choices.
